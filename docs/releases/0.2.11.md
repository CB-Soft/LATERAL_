# LATERAL_ 0.2.11 — PhoneView and display fixes

- PhoneView: fullscreen landscape BeastUI on the phone with native Android mouse and external keyboard input.
- Display-menu toggle in both UIs; connection offer; automatic exit on keyboard removal or external-display connection.
- Fixed primary/secondary mouse handling, touch UP/MOVE conversion, and hosted-display focus stalls. Modifier and key-up events are preserved.
- External-display handoff retains hosted tasks and restores PhoneUI.
- Preserved display/density tweaks and fixed supersampling clipping at high raster density and small presentation scales.
- Agent controls/runtime remain off main; agent work is preserved on LATERAL_dev. The unrelated USB/ADB bridge prototype is not included.

SDK-free stable APK, signed with the same certificate as the previous published stable release. Install as an update. Reconnect/restart the privileged bridge after updating so the new helper is loaded.

Validation: 17 unit tests, release build/lint, signed emulator upgrade, native touch/mouse/wheel/keyboard event delivery, and PhoneView lifecycle/handoff on Android 15. Physical Nubia peripherals and VITURE timing modes still need hardware regression. See the repository's docs/PHONEVIEW.md for test notes.
