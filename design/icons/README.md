# LATERAL_ icon directions

These explorations translate the outline into a compact app mark:

- `lateral-icon-brackets-row.svg` — neutral typographic row: `[ ] [ ] [ ]` with segmented underscores as the bottom bar.
- `lateral-icon-brackets-focus.svg` — selected direction: the focused middle task and its taskbar segment use a muted Nordic blue/cyan accent.
- `lateral-icon-brackets-focus-purple.svg` — alternate accent direction using a restrained cool purple.
- `lateral-icon-brackets-cursor.svg` — alternate direction: a vertical focus cursor moves through the task row.

- `lateral-icon-task-strip.png` — selected direction: a horizontal task strip with one amber focused task and a rightward movement cue.
- `lateral-icon-rail.png` — alternate direction: a phone/control rail crossing the workspace.
- `lateral-icon-cursor.png` — alternate direction: a focus cursor moving across task lanes.

The bracket/focus direction is integrated into the Android adaptive launcher icon. The live launcher uses Nordic cyan (`#79C7D3`); purple (`#A98BFA`) is kept as an alternate direction.
